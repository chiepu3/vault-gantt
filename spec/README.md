## データが消える・壊れる

### PR #15　期限を変えただけで、自分で書き足した内容が消える
**どんな時**：タスクのノートに、自分で `project: 顧客A` のようなプロパティや「## 参考資料」のような見出しを書き足している。
**今の動き**：ワークベンチで期限を変えるなどして保存すると、ノートがプラグインの決まった形で丸ごと書き直され、書き足した部分が**消える**。
**修正後**：プラグインが管理する部分だけ書き換え、書き足した部分は残す。
**失うもの**：書き方によっては保存できず通知が出ることがある。プロパティの並び順が変わることがある。

| 今：`project` と「参考資料」が消えた | 修正後：残っている |

### PR #11　見出しを並べ替えると、別のサブタスクの期限が付く
**どんな時**：ノート本文でサブタスクの見出し（「設計」「実装」）の順番を入れ替えた。
**今の動き**：プラグインは見出しを「上から何番目か」で対応させているので、**設計の期限が実装に、実装の期限が設計に**表示される。
**修正後**：見出しの名前で照合し、合わなければ編集を止める。
**失うもの**：**そのタスクが一覧から消える**。お知らせも画面に出なかった。おすすめしない（直すならもっと親切な形にしたい）。

| 今：期限が入れ替わって表示 | 修正後：一覧から消える |
|---|---|
| <img src="02/before.png"> | <img src="02/after.png"> |

### PR #13　Gantt でサブタスクを追加すると、直前のノート編集が消える
**どんな時**：Gantt でサブタスク追加の画面を開いている間に、親ノートのメモや期限を書き換えた。
**今の動き**：追加した瞬間、画面を開いた時点の古い親ノートで上書きされ、**直前に書いたメモと期限が消える**。
**修正後**：追加する直前に最新のノートを読み直す。
**失うもの**：ほぼなし。

| 今：メモと期限が消えた | 修正後：残っている |
|---|---|
| <img src="04/before.png"> | <img src="04/after.png"> |

### PR #18　タグを YAML のリストで書くと消える
**どんな時**：Obsidian 標準のプロパティ欄でタグを編集した（Obsidian はタグを `- work` のようなリスト形式で書く）。
**今の動き**：プラグインは `tags: work, urgent` の1行形式しか読めないので、タグなしと見なし、次に保存した時に**タグが消える**。
**修正後**：リスト形式も読み、`["work","urgent"]` の形で保存する。
**失うもの**：タグを手で `work, urgent` と書いているなら不要。保存形式が変わる。

## 元に戻せない

### PR #16　追加・削除をすると、それより前の「元に戻す」が全部消える
**どんな時**：期限を変えた後、Gantt でサブタスクを追加した。
**今の動き**：追加・削除のたびに Undo 履歴が全消去され、**期限の変更も戻せなくなる**。
**修正後**：追加・削除も履歴に記録し、前の操作も順に戻せる。
**失うもの**：履歴の分メモリを少し使う。
※ Daily ToDo の保存はポップオーバー化（PR #26）で既に戻せるようになった。残っているのは Gantt の追加・削除。

## 操作によって結果が違う

### PR #19　同じ「1日右へ」でも、まとめて動かすと土曜日に置かれる
**どんな時**：金曜（10/9）のタスクを1日右へ動かす。10/12 は祝日。
**今の動き**：1つだけ動かすと休日を飛ばすのに、「これ以降を纏めて移動」だと**土曜（10/10）に置かれる**。
**修正後**：まとめて動かしても休日を飛ばす（この例では 10/13 火）。
**失うもの**：まとめて動かした時、タスク同士の「暦日の間隔」は保たれなくなる。
