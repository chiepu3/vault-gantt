# デザイン統一の前後比較（左＝前、右＝後）

コンセプトはそのまま、余白・角丸・色・文字サイズ・影・ボタン・タグの形を共通ルール（`--vg-*`）に揃えました。画像は合成データ、Obsidian 1.13.4。AIチャット画面は PR #9 と重なるため対象外。
